## Consignas

El proyecto debe cumplir con las siguientes consignas:

1. **Crear el esquema de la base de datos** utilizando JDBC.

2. **Cargar los datos desde los archivos CSV** proporcionados, utilizando JDBC y la biblioteca [Apache Commons CSV](https://commons.apache.org/proper/commons-csv/) para su lectura.

3. **Obtener el producto que más recaudó**, considerando como recaudación la cantidad de unidades vendidas multiplicada por el valor del producto.

4. **Obtener una lista de clientes ordenada por el monto total facturado**, de mayor a menor.
